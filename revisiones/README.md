# Revisiones

Informes de las revisiones hub-spoke (skill `revisar-seccion`), una carpeta por sección. Cada archivo lleva el número de ronda delante: `61-junior-r5.md` es el informe del junior en la ronda 5.

Son notas de trabajo, no fuentes. Muchos informes proponen datos que una ronda posterior corrigió o quitó. Antes de usar un dato de aquí, compruébalo en la documentación oficial.

Jekyll no publica esta carpeta: el sitio se construye desde `src/`.
